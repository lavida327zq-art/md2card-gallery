# 城市边的森林，是一剂处方药

住在钢筋水泥里太久，人会长出隐形的刺。我给自己开的方子很简单：每周去一次 **城郊的林地**，让松针的气味把神经 *捋顺*。大自然从不多话，却总能把 ***过载的脑子*** 调回出厂设置。那些失眠的夜晚，~~从踏青后少了许多~~。医生说多走走路，森林说「不用挂号，直接来」。

> 走进森林，不是逃离生活，是回去充电。

![林间小径](https://picsum.photos/seed/forest-path/600/400)

## 森林散步指南

### 一、出发前准备

轻装，但别马虎：

- 穿一双抓地好的旧鞋，泥路更稳
- 带一瓶水与一小包坚果，不依赖补给
  - 森林里信号弱，提前下载离线地图
- 把闹钟调早一小时，赶在人流前，独享晨雾

### 二、路上的观察法

1. 每走百步，停下听一种声音
2. 用手机记下三种没见过的植物
3. 回程时只带照片，不留痕迹

- [x] 走完 5 公里环线
- [x] 认识银杏与枫的区别
- [ ] 拍到一只松鼠

| 时长 | 2 小时 | 达成 |

森林最神奇的地方，是它不收费，却给得最多。一棵老树站了几百年，看尽人来人往，依旧安静地绿着。站在它下面，人那点烦恼忽然有了比例尺——原来很多事，根本不值得占用心里的位置。走进森林不是逃离生活，是回去充电，再带着满格的自己，体面地回到人间。下次，还来。森林不语，却把什么都给了。

## 把自然带回家

捡一片形状好看的叶子夹进书里，城市里的某个深夜，它会替森林来看你。

## 记录自然的脚本

把每次徒步的数据留档，慢慢就成了一本自然志：

```python
trail = {"date": "2026-08-14", "km": 5.2, "species": 3}
print(f"今日林间：走了 {trail['km']} 公里，遇见 {trail['species']} 种植物")
```
