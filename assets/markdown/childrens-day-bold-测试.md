# 🎈 给大朋友的一份儿童节礼物清单

谁说成年人不能过六一？今天我把工作台涂成了 **蜡笔色**，把待办本画成了 *贴纸墙*，决定认真地 ***宠自己一次***。那些「已经长大了」的规矩，~~先扔到一边~~。长大最酷的地方，是有能力给童年的自己，补一份迟到但真诚的礼物。

> 长大不是失去童心，是把童心藏进更结实的外壳里。

![彩色蜡笔](https://picsum.photos/seed/kids-crayon/600/400)

## 今天就要做的快乐小事

### 早餐：把牛奶画成笑脸

别急着开会，先让胃开心起来：

- 用可可粉在奶泡上画一个歪歪的笑
- 挑一首小时候最爱的动画片主题曲当 BGM
  - 推荐《数码宝贝》或者《樱桃小丸子》
- 把窗户擦干净，让阳光进来，和笑脸合影

### 午后：把工作变成游戏

1. 每完成一项任务，就贴一张星星贴纸
2. 用彩色便利贴重写三条周目标
3. 下班前给自己盖一个「今日也很棒」的章

- [x] 买一盒小时候最爱的草莓味棒棒糖
- [x] 给最好的朋友发一句「儿童节快乐」
- [ ] 拼完那盒落灰的乐高

| 礼物 | 预算 | 快乐指数 |
| --- | --- | --- |
| 棒棒糖 | ¥5 | ★★★★ |
| 乐高 | ¥199 | ★★★★★ |
| 一场动画 | 免费 | ★★★ |

说真的，成年人最缺的不是钱，是被允许「不务正业」的权限。六一这一天，我郑重地把这个权限发给自己：可以傻笑，可以乱画，可以为一颗糖开心半天。长大最浪漫的副作用，是终于有能力宠一宠当年的自己，不用等任何人批准。

## 快乐也要记一笔

把今天的开心存档，月底翻看会发现自己原来这么容易满足。童心不贵，贵在记得。

## 用代码召唤童心

写个小函数，每天随机抽一个「今天也要开心」的理由：

```js
const reasons = ["吃糖", "画画", "发呆", "晒太阳"];
const pick = () => reasons[Math.floor(Math.random() * reasons.length)];
console.log("今天也要" + pick() + "！");
```

童心不贵，[贵在记得](https://example.com)。六一快乐，大小朋友。
