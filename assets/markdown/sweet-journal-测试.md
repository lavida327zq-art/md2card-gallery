# 我的粉色手账，第七天

翻开这本 *奶油粉* 封面的小本子，第七天的贴纸已经贴到边角微微翘起。我给它画了一个 **歪歪的太阳**，又用胶带粘上一片捡来的樱花瓣。手账的意义，是把普通的日子 ***裱进框里***。那些觉得「不值得记」的瞬间，~~其实最该留住~~。写手账的第七天，我发现自己开始主动制造小确幸——只为了有东西可贴。

> 认真装饰生活的人，生活也会回赠糖。

![手账内页](https://picsum.photos/seed/sweet-journal/600/400)

## 这周的手账拼贴

### 一、贴纸收藏册

每去一个地方就囤一点可爱：

- 便利店限定的水果贴纸，已集齐三种
- 朋友送的猫咪火漆章，盖在扉页
  - 配蕾丝花边刚刚好，像给文字系上蝴蝶结
- 把电影票根也贴进去当回忆，比照片更有触感

### 二、本周小确幸清单

1. 买到心心念念的薰衣草香水
2. 学会用缝线胶带做旧边
3. 和闺蜜视频聊到睡着

- [x] 完成月度手账拼贴

- [ ] 尝试新出的草莓胶带上手

翻着手账，我突然懂了：所谓仪式感，不过是把「我在认真活」这件小事，具象成看得见的痕迹。贴纸会翘边，墨水会褪色，但那一刻的心动是真的。多年后翻开，纸会替我记得，今天曾那样用力地开心过。可爱不是幼稚，是成年人稀缺的、对生活温柔以对的能力。

## 可爱是一种生活态度

手账教会我的，不是怎么贴得好看，而是愿意为平凡的一天，多花一点点心思。

## 手账里的可爱代码

顺手写了个随机鼓励小函数，贴在手账背面：

```js
const cheers = ["你超棒", "慢慢来", "被爱着"];
const say = () => cheers[Math.floor(Math.random() * cheers.length)];
console.log("今天的你：" + say());
```
