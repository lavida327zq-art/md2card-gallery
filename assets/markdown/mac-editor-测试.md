# 把重复劳动，交给一个快捷键

我花了两周，把每天最烦的 **三件事** 自动化了。现在它们只占 *一次设置* 的功夫，之后全自动跑。效率工具的意义，不是让你做更多，而是 ***把时间还给你***。那些手动复制粘贴的夜晚，~~终于结束了~~。算一笔账：每天省下四十五分钟，一年就是整整十一个工作日，够休一次假。

> 最好的工作流，是你看不见它，它却一直在跑。

![编辑器窗口](https://picsum.photos/seed/mac-editor/600/400)

## 我的 AI 工作流三板斧

### 一、自动化收集

灵感、链接、截图不再散落各处：

- 用快捷键把网页一键存进笔记
- 微信文件自动归类到「待处理」文件夹
  - 按来源打标签，检索秒回，不再翻聊天记录
- 每日晨间脚本汇总昨日碎片，生成晨报

### 二、让 AI 先打草稿

1. 把原始素材丢给模型生成大纲
2. 人工只改结构与语气，不从头写
3. 定稿自动推送，省去来回拷贝

- [x] 配置剪藏快捷键
- [x] 写好日报模板
- [ ] 接入日历自动排程

| 环节 | 手动耗时 | 现在 |
| --- | --- | --- |
| 收集 | 15 分 | 1 分 |
| 起草 | 40 分 | 10 分 |
| 推送 | 5 分 | 0 分 |

有人问我值不值得花两周折腾。我的答案是：但凡每周能省下四十五分钟，两周就回本了，之后全是赚的。自动化的魅力不在当下，而在它替你运行的每一个明天。一次 setup，长期分红；把重复的苦差事交给机器，把稀缺的注意力留给人真正擅长的创造。这账，怎么算都划算。

## 把重复交出去

工具替你做的越多，你留给创造的空间就越大。自动化的终点，是被释放的注意力。

## 一行命令跑起来

把晨间汇总写成脚本，定时执行最省心：

```bash
#!/bin/bash
# 汇总昨日收藏并生成晨报
python summarize.py --since yesterday | tee morning.md
open -a "Typora" morning.md
```

把重复交出去，[把创造留给自己](https://example.com)。
