# 信息焦虑，是一场自己吓自己

刷不完的信息流、回不完的消息、看不完的课程——我们把 **注意力** 当成了 *无限资源*，结果被 ***三路洪流*** 同时淹没。那些「怕错过」的紧迫感，~~大多只是算法的诱饵~~。我统计过自己一天点亮屏幕的次数：一百三十二次。其中真正必要的，不到十次。

> 你不是不够努力，你只是给输入端喂得太多。

![信息洪流](https://picsum.photos/seed/info-flow/600/400)

## 三步，把洪流关小一点

### 第一步：给输入端减肥

订阅越多，噪声越大。我的做法是先把水龙头关小：

- 取关所有「看了更焦虑」的账号
- 把新闻压缩成每天一次的集中阅读
  - 用 RSS 替代算法推荐，把主动权拿回来
- 关闭非必要的 App 红点提醒，眼不见心不烦

### 第二步：建立过滤漏斗

1. 只保留「下周用得上」的内容
2. 长文先存后读，不当场消化
3. 每周清空一次收藏夹，只留行动项

- [x] 删掉 30 个闲置订阅
- [x] 把手机调成灰度模式
- [ ] 写一份个人「信息食谱」

| 来源 | 频率 | 去留 |
| --- | --- | --- |
| 社群消息 | 高 | 限流 |
| 长文订阅 | 中 | 保留 |
| 短视频 | 高 | 戒断 |

有意思的是，当我真的开始做减法，产出反而高了。注意力是稀缺资源，护住它，比拼命摄取更重要。信息节食不是苦行，是把带宽留给真正热爱的事。少看一点，多活一点；少囤一点，多想一点。清空不是失去，是腾出空间接住更好的东西。

## 少，是一种主动的选择

清空不是失去，是把带宽留给真正重要的事。信息节食一周后，我睡得好了，想法也清楚了。

## 一套极简过滤模型

把「该不该看」抽象成一个函数，让决策不再内耗：

```python
def keep(info, rule):
    """rule 返回 True 才留下，否则直接丢弃。"""
    return info if rule(info) else None

useful = keep("新出的 AI 课程", lambda x: "下周能用" in x)
print(useful or "跳过，不焦虑")
```

少即是多。详见 [极简主义指南](https://example.com)。
