# 一份关于「松弛感」的入职宣言

我来团队的第一天，没背稿子，只带了一支笔和 **一张白纸**。我想说的很简单：工作可以认真，但不必 *紧绷*。最好的状态，是 ***手里有事，心里有空***。那些为了显得忙而忙的表演，~~我打算先戒了~~。白纸黑字，反而比花哨的 PPT 更有分量——这是我给自己定的第一课。

> 把事做漂亮，也把自己照顾好，这才叫专业。

![手绘工位](https://picsum.photos/seed/ink-desk/600/400)

## 我打算这样工作

### 一、把节奏交还自己

不追逐每一声通知，先护住专注：

- 上午留给最需要脑力的那件事，微信免打扰
- 把会议压缩进两个固定时段，其余时间静音
  - 深度工作两小时，抵过碎片化一整天
- 周五下午留白，用来复盘与发呆，不排会议

### 二、用笔记代替脑子

1. 所有灵感先落纸，不靠记忆
2. 周一一页计划，周五一页回顾
3. 文档公开，欢迎任何人来改

- [x] 搭好个人知识库骨架
- [x] 写下团队协作三原则
- [ ] 做一次公开分享

| 原则 | 说明 | 落地 |
| --- | --- | --- |
| 坦诚 | 有话直说 | 是 |
| 留白 | 不排满 | 否 |
| 复盘 | 周周有 | 是 |

白纸黑字的好处，是逼你想清楚再落笔。花哨的排版能掩盖逻辑的空洞，朴素的形式不行。所以我偏爱这种克制：把内容本身打磨好，装饰交给留白。专业，从来不需要喧哗来证明。把事做漂亮，也把自己照顾好，这两者并不矛盾，反而互相成全。

## 松弛，是更高级的专业

不紧绷不代表不负责，而是把能量用在刀刃上。愿我们都能，认真而不狼狈。

## 顺手写的待办小工具

用最朴素的脚本，把今天的清单打印出来贴墙上：

```python
todos = ["写周报", "约同事午饭", "散步十分钟"]
for i, t in enumerate(todos, 1):
    print(f"{i}. {t}  {'✓' if i < 2 else ''}")
```
