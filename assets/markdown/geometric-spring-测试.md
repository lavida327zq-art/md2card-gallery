# 把阳台，改成春天的样子

三月一来，我就把厚窗帘换成 **亚麻白**，又搬回一盆 *风信子*。阳光斜进来时，整个房间像被 ***调成了一杯气泡水*** 的色调。那些过冬的沉闷，~~终于肯退场~~。邻居阿姨探头说「你家亮了」，我才知道，春天是被布置出来的，不是等来的。

> 春天不是等来的，是动手布置出来的。

![春日阳台](https://picsum.photos/seed/spring-balcony/600/400)

## 春日阳台改造计划

### 一、先换一盆会开花的

不必大动干戈，从最小的一步开始：

- 把枯了的绿萝剪掉，换上郁金香种球
- 在窗台铺一条几何纹样的棉麻布
  - 黄白格纹最衬春日光线，像打翻的奶油
- 挂一串纸艺小旗，风一吹就摇晃，像在打招呼

### 二、给阅读角腾地方

1. 把杂物箱挪到床底，腾出半平米
2. 摆一张矮木几，放茶与书
3. 加一盏暖光小灯，傍晚刚刚好

- [x] 买齐三种春色花瓶
- [x] 重读《人间草木》前两章
- [ ] 邀请朋友来喝一次春茶

| 物件 | 颜色 | 到位 |
| --- | --- | --- |
| 风信子 | 紫 | 是 |
| 棉麻布 | 米白 | 是 |
| 小旗 | 多彩 | 否 |

朋友说，你这哪是改造阳台，是给心情换了滤镜。我笑而不语——可别说破，仪式感最怕被看穿。生活的甜，往往就藏在这些「没什么用」的折腾里。一盆花、一块布、一串小旗，足够把平凡的一天，过成自己想要的样子。不必等春天正式报到，先让自己住进春天里。光是想想，就觉得日子有盼头。

## 把春天留成习惯

不指望一次布置管一整年，但每个季节换一盆花，日子就有了刻度。生活的仪式感，往往就这么简单。

## 顺手写个春日配色

把这几天的灵感存成一段 CSS 变量，下次直接复用：

```css
:root {
  --spring-sky: #EAF2E9;
  --spring-sun: #F6E7B8;
  --spring-flower: #C98AA6;
}
.balcony { background: var(--spring-sky); }
```

春天很短，[趁现在](https://example.com) 布置起来吧。
