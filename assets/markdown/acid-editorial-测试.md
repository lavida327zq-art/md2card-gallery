# 把「钝感力」装进八月

八月临近尾声，我终于把那本翻烂的《被讨厌的勇气》合上，在备忘录里写下四个字：**钝感力**。所谓钝感，不是麻木，而是 *有意识地* 给情绪加装一层缓冲——对无关的眼光 ***慢半拍回应***，对恶意的揣测 ~~反复内耗~~。这一整月，我像在做一场安静的实验：把敏感的触角收一收，看生活会不会反而更轻。

> 敏感是天赋，但钝感是修行。真正的松弛，是允许自己「听不懂」别人的潜台词。

## 这个月，我悄悄重修了三件事

### 一、对评价脱敏

以前发一条动态，会盯着 `点赞数` 反复刷新。现在我给自己定了一条铁律：先把期待降到零，再谈表达。具体来说——

- 写完即放下，不回看前两小时的数据
- 把「TA 是不是在说我」翻译成「TA 在说 TA 自己」
  - 这招对职场群聊尤其管用，省下无数内耗
- 留出每晚 20 分钟的「无手机时间」，只和自己待着

### 二、把大事拆成清单

1. 周日定下本周唯一目标，其余都是杂音
2. 每天只挑一件最难的事先做，吃掉青蛙
3. 睡前用三句话记录完成度，不写小作文

- [x] 读完《纳瓦尔宝典》并做卡片笔记
- [x] 戒掉睡前刷短视频
- [ ] 把积压的邮件清空到零

## 三、给回忆留一个出口

月底翻看日记，发现最珍贵的不是成就，而是那些被允许「什么都不做」的下午。钝感不是变迟钝，是把能量从揣测别人，挪回照顾自己。

## 我的复盘小工具

用一段脚本把每天的日记自动归档，省去手动整理的麻烦：

```python
from pathlib import Path

def archive(entry: str, day: str):
    folder = Path(f"journal/{day[:7]}")
    folder.mkdir(parents=True, exist_ok=True)
    (folder / f"{day}.md").write_text(entry, encoding="utf-8")
    return f"已归档 {len(entry)} 字"

print(archive("今天学会了不对评价过敏。", "2026-08-14"))
```
