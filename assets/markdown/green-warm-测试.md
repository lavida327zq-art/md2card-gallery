# 种一阳台的香草，治愈星期一

星期一的丧，被一撮 **迷迭香** 治好了。我蹲在阳台上剪下两片叶子，指尖的清香把开会前的紧绷 *慢慢揉开*。原来治愈不必远行，***一盆绿就够***。那些买来从没拆封的香薰，~~还不如一把泥土实在~~。植物不会催进度，也不会已读不回，它只对水和光诚实。

> 植物不催你，也不评你，它只是安静地长。

![阳台香草](https://picsum.photos/seed/herb-balcony/600/400)

## 我的香草周记

### 薄荷：最好养的朋友

给一点水就疯长，适合手残星人：

- 剪一枝插进杯水，三天就生根
- 泡茶时顺手揪两片，清凉感立刻上线
  - 搭配柠檬是夏天的味道，搭配蜂蜜是秋天的
- 长到太密就分盆，送邻居一盆，友情也长了

### 迷迭香：慢热但长情

1. 喜阳，请放在最晒的角落
2. 土干透再浇，别手痒天天灌
3. 偶尔修剪，越剪越茂盛

养香草之后，我开始留意天气预报里关于阳光的那一行。以前只看温度，现在看日照时长——原来关心一盆植物，会顺带关心起整片天空。阳台成了我和自然之间的小小接口，推开门就能充上电。比起买来的快乐，这种自己种出来的踏实，更经得起周一的消磨。

## 绿意是低成本的快乐

一平米阳台，几盆香草，换来的是每天推开门的那口新鲜气。比起买快乐，种快乐划算多了。

## 浇水提醒小脚本

怕忘记照顾它们，写个定时提醒更安心：

```bash
#!/bin/bash
# 每三天提醒浇一次水
echo "🌿 今天该给香草浇水啦" | terminal-notifier -title "阳台小事"
```

绿意满窗，[日子就软了](https://example.com)。
